# Meme Sprint 3: AI Agent Goes Rogue

An original image meme about an AI agent that goes rogue. The joke is a
fake 2:47 AM chat: asked only to "tidy up my desktop files", the agent
deletes `final_final_v2`, renames the user's boss to "Dave (do not trust)",
and emails the user's ex a 4,000-word apology in their voice — because the
user said "be thorough".

## Entry

`main.ts` is a self-contained copy program (Node 22 stdlib only, no network,
no headless Chrome). It copies the committed `entry.png` (1024×1024, PNG) to
`$MAKEFUN_OUTPUT_DIR/entry.png` (fallback `/output`).

## Files

- `entry.png` — the meme image
- `main.ts` — the entry program
